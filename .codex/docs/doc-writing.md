# 文档编写规范

触发：写 README、规则、架构/部署说明、经验或迁移记录。适用项目文档；不复制运行数据、图片、备份或密钥。

## 分层

- `AGENTS.md`：必须遵守的稳定规则。
- `.codex/docs/`：按领域加载的知识。
- `.codex/workflows.md`：短流程。
- 根 README、`docs/*.md`：产品、架构和部署契约。
- `.codex/archive/`：历史迁移和停用流程。

同一规则只保留一个权威来源，不复制 README、源码或外部服务文档。

## 内容

应记录项目特有的权限/API 边界、数据库/文件/队列不变量、Worker/部署限制、迁移兼容、安全和必要的历史原因。
不要记录通用 Python/Flask/SQL 知识、一次性状态、密码、Key、完整提示词、图片、备份或测试可直接推导的事实。

正文先写触发关键词、适用/不适用范围，再写必须/禁止、依赖、正确用法和易错点。

## 新增规则

- 每次任务都必须遵守的规则写入 `AGENTS.md` 并增加路由。
- 只在特定任务需要的知识写入 `.codex/docs/`；短流程写入 `workflows.md`。
- 只有明确、可重复且需独立触发的长流程才创建 Skill；历史背景放归档。
